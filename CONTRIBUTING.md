# Contributing

This repository holds a graded course project (22AIE301, Team D16). **It does not accept outside contributions.**

* Pull requests are not accepted unless the repository owner (@ManoharPaturi) has asked for them in advance.
* Every change to `main` must be approved by the owner, including changes from collaborators.
* Pull requests, issues and comments from accounts that are not collaborators are currently disabled.

If you find a bug or have a question, contact the owner through GitHub.

You are welcome to read, clone and run the code for study purposes.
